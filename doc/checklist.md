# `infs803-a1` — build checklist

The **single** living tracker for the deliverable. Derived from `rubric.md` —
which holds the marking criteria only — but organised the way we're *working*,
not the way the document is structured.

The document itself is written in `<Word / Google Docs / …>` and stays
reader-first: structured by professional convention, with rubric coverage
proven by a mapping table. This file tracks decisions, drafts and progress; it
is not the deliverable.

## How this file works

Every item is a `###` sub-section with the same shape. Sections are omitted
when they'd be empty, never reordered:

- **What the rubric wants** — one line, so the item's purpose is never lost
- **Decisions** — what was chosen, and why
- **Draft** — the current text, verbatim, as a blockquote
- **Sources** — claim · source · strength
- **Open** — checkboxes for what's unresolved

Status is a word, not a glyph: `todo` · `drafting` · `drafted` · `done`.
